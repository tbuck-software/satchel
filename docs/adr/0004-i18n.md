# 0004 Internationalisierung mit `vue-i18n`, Englisch als Default

Status: umgesetzt 2026-08-29, ersetzt die Regel „UI-Texte auf Deutsch" in CLAUDE.md

Frontend, Viewer, Tray und die nativ gerenderten Betriebssystem-Flächen sind
umgestellt. Alle falliblen Tauri-Command-Grenzen liefern den strukturierten
`{ key, params }`-Fehlervertrag. Technische Details dürfen intern als String
existieren, werden an der IPC-Grenze aber zu Parametern und nicht als
Benutzersprache gerendert. Native Kaltstart-Defaults werden aus dem kanonischen
Katalog generiert; danach liefert das Frontend die aktive Übersetzung über
`set_ui_strings`.

## Kontext

~2.000 UI-Strings in ~130 Komponenten sind deutsch und stehen direkt im
Template. Open Source mit deutscher Oberfläche schließt fast alle
Beitragenden aus.

## Entscheidung

- `vue-i18n`, kein Eigenbau. Englisch (`en`) ist Default und Fallback,
  Deutsch (`de`) die erste weitere Sprache.
- Rust liefert **Message-Keys plus Parameter**, nie fertige Sätze; das
  Frontend übersetzt. Betrifft Notification-Texte, Tray-Menü,
  Fehlermeldungen.
- Umsetzung **nach** Hygiene und mechanischem Crate-Split (0003), damit
  nicht Code übersetzt wird, der gleich zerlegt wird.

## Konsequenzen

CLAUDE.md-Regel wird zu: „UI-Strings nur über `t()`; Klartext im
Template ist ein Bug." Die Playwright-Smoke-Tests prüfen gegen `en`.
